# Moth V0.2 当前实施计划

这份计划把 `CORE.md` 约束落成一个可发布的、单用户、Filesystem First 在线优先 PWA。它不扩展到离线阅读、文件整理、多用户或额外格式。

## 目标架构

```text
只读 Library roots
        ↓
增量 Scanner
        ↓
SQLite: Library → Directory → Publication
        ↓
格式层：EPUB Range / TXT byte range / CBZ page / MOBI→EPUB
        ↓
认证 REST API
        ↓
简体中文 PWA 阅读器
```

## 阶段

1. **收缩基线**：使用一个干净初始 migration，拒绝旧 schema；删除 organization/offline/IndexedDB 链路、旧 `/books` 契约和双语文案。
2. **Filesystem First**：读取 TOML 多 Library；未设置时回退 `MOTH_BOOKS_DIR`；建立显式目录树、增量扫描、唯一移动识别、重复哈希保留和完整扫描 prune 保护。
3. **格式层**：EPUB 只做源文件 Range；TXT 建立编码/章节/UTF-8 byte-range 索引；CBZ 建立自然页序并按页解压；MOBI 按内容版本生成最小 EPUB3 缓存。
4. **进度**：使用 EPUB/TXT/CBZ 判别式 locator；校验格式和 `0..1`；content version 变化时保留总体进度并丢弃精确 locator；客户端防抖、逐书最后写入。
5. **V0.2 UI**：首页继续阅读、最近添加、小说、漫画、目录；目录面包屑和多库切换；标题/作者/文件名搜索；统一文字阅读器；CBZ 单页/双页/Webtoon、LTR/RTL、适应宽度/高度和触摸。
6. **发布收尾**：Service Worker 只预缓存 shell/assets；清理 Foliate 无关文件；更新 README/TODO/Compose/验收矩阵；完成 Rust、前端、Playwright、Docker 和真机检查。

## 验收原则

- 原始书库只读，任何缓存和数据库写入均位于数据目录。
- 不承诺 AZW3/KF8、PDF、FB2、DRM MOBI；错误信息引导用户转换为 EPUB。
- 旧数据库、旧 API、旧 IndexedDB 均不兼容；升级流程是备份、删除 `moth.db`（含 WAL/SHM）、重新扫描。
- 外部环境未执行的浏览器、移动端、Docker 权限和信号测试必须保持待验收状态。

逐项状态见 [`docs/v0.2-acceptance.md`](../v0.2-acceptance.md)，产品范围以 [`CORE.md`](../../CORE.md) 为准。
