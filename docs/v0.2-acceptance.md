# Moth V0.2 验收矩阵

本文件与 `CORE.md`、README 和 TODO 一起构成当前发布依据。V0.2 是在线优先产品：断网只能启动应用外壳，阅读资源和进度请求需要服务器连接。

## 范围与数据

| 场景 | 期望 | 当前证据 |
| --- | --- | --- |
| 干净数据库 | 只创建 `libraries`、`directories`、`publications`、`text_chapters`、`cbz_pages`、`reading_progress` 与认证表 | Rust `db` 单测 |
| 旧数据库 | 启动前拒绝旧表/旧迁移，并提示备份后删除 `moth.db`、WAL/SHM、重新扫描 | Rust `db` 单测 |
| TOML Library | 唯一非空 key/name/path；缺失显式配置报错；未设置时回退 `MOTH_BOOKS_DIR` | Rust `config` 单测；需补多库现场验收 |
| 只读源目录 | 扫描只读 NAS，不向源目录写入；派生缓存只写 `/data` | scanner 实现；需容器冒烟 |
| 增量扫描 | size/mtime 未变跳过；修改重建解析索引；唯一移动沿用 publication ID；重复哈希不合并；完整扫描后删除确认消失项 | scanner 实现；需补文件系统回归 |
| 不完整扫描 | 根目录不可读或中途 I/O 失败时不 prune | scanner 实现；需补故障注入回归 |

## 格式与阅读

| 格式 | 验收点 | 当前证据 |
| --- | --- | --- |
| EPUB | 元数据/封面/TOC；源文件 HTTP Range、ETag、If-Match；浏览器使用 EPUB 分页和 CFI | `moth-format` 单测、生产构建；需 Playwright/真机 |
| TXT | UTF-8/UTF-16/GBK/GB18030/Big5；中文章节规则；byte-range 随机读取；手动编码切换 | Rust TXT 单测、前端 reader 单测；需大文件回归 |
| CBZ | 自然排序、按页 ZIP 解压、单页/双页/Webtoon、LTR/RTL、适应屏幕/宽度/高度、触摸翻页 | Rust CBZ 单测、前端组件；需 Playwright/移动 viewport |
| MOBI | 只承诺经典无 DRM；扫描元数据/封面；首次打开转换最小 EPUB3；缓存命中、源/转换器版本失效、并发去重、失败可重试 | Project Gutenberg fixture Rust 单测；需转换 API/E2E |
| 不支持格式 | AZW3/KF8/PDF/FB2 等不进入索引或返回清晰的 EPUB 转换提示 | `BookFormat` 单测；需 API 验收 |

## API、进度与前端

| 场景 | 验收点 | 当前证据 |
| --- | --- | --- |
| Publication API | `/home`、`/libraries`、`browse`、`publications`、资源、conversion、progress 和 scan 状态均使用 Publication 命名 | Axum router、TypeScript API |
| 搜索筛选 | 标题/作者/文件名搜索，作者字符串筛选，格式和 Library 筛选，最近添加排序 | SQL 查询与首页实现；需 E2E |
| 进度 | EPUB/TXT/CBZ 判别式 locator；范围和格式拒绝；content version 变化保留总体进度并丢弃精确定位；PUT 最后写入生效 | Rust 校验/回退实现；需 API 并发回归 |
| 首页与返回 | 继续阅读、最近添加、小说、漫画、目录入口；目录面包屑和阅读返回状态 | React 页面；需 E2E |
| Service Worker | 只缓存 shell/构建资源；API、认证、书籍文件、章节和页面不进入 Cache Storage 或 IndexedDB | `web/public/sw.js`、构建 precache；需浏览器验收 |
| 认证与响应头 | 单用户 session、HttpOnly cookie、安全响应头、非 root Docker | 现有 auth/HTTP middleware；需容器验收 |
